# MacClipboard 产品需求文档 (PRD)

> 版本：v0.1 锁定版（macOS）
> 状态：规划中
> 平台：macOS 13 Ventura+
> 技术栈：Tauri 2.0 + React + TypeScript + Rust + SQLite
> 关系：与 Windows 版 `PRD.md`（WinClipboard v0.1）平行；跨平台能力对齐，平台细节各自独立

---

## 一、产品定位

### 1.1 一句话定位

**AI-Native 极简 macOS 剪贴板工具** —— 轻量、极速、隐私优先，"复制即处理"，菜单栏常驻、Spotlight 式光标唤起。

### 1.2 目标用户

| 用户群           | 占比预估 | 核心痛点                                        | 付费意愿 |
| ------------- | ---- | ------------------------------------------- | ---- |
| 开发者（陈工）       | 25%  | 频繁复制 JSON/SQL/代码，需格式化和片段管理                  | 中    |
| 译者/内容运营（小宇）   | 50%  | 频繁复制中英文，需润色/翻译/清理格式                         | 中高   |
| 自媒体创作者（林姐）    | 15%  | 标题/模板复用，需改写                                 | 高    |
| 隐私敏感用户（Kevin） | 5%   | 拒绝云端，本地优先                                   | 中    |
| 现有解法          | —    | Maccy（免费轻量）/ Paste（付费精美）/ Raycast（launcher） | —    |

### 1.3 差异化策略

| 维度     | Maccy | Paste   | Raycast  | 原生 Universal Clipboard | **我们**             |
| ------ | ----- | ------- | -------- | ---------------------- | ------------------ |
| UI 现代化 | ✅ 极简  | ✅ 顶级时间轴 | ✅ 顶级     | ❌ 无界面                  | ✅ 原生 vibrancy      |
| AI 原生  | ❌     | ❌       | ⚠️ 通用    | ❌                      | ✅ **专用**           |
| 中文场景   | ❌     | ❌       | ⚠️       | ❌                      | ✅ **主战场**          |
| 内容智能动作 | ❌     | ❌       | ❌        | ❌                      | ✅ **JSON/HTML/图片** |
| 性能     | ✅ 极轻  | ⚠️ 较重   | ⚠️ 较重    | —                      | ✅ **极致**           |
| 商业模式   | 免费开源  | 付费买断    | 免费 + Pro | 系统自带                   | 免费 + AI 订阅         |

> Mac 端三竞品都没真正做好"剪贴板内容智能动作"——这是与 Windows 版一致的核心切入差异。

## 二、市场背景

### 2.1 存量市场成熟

- macOS 剪贴板市场已被 Maccy（免费开源、轻量）、Paste（付费、时间轴 UI）、Raycast（免费 launcher，剪贴板为内置功能之一）瓜分
- 原生 Universal Clipboard 仅做跨设备同步，无历史/无智能
- 大厂入局风险：Apple 可能在系统更新中集成 AI 剪贴板（Fn 键调出 Clipboard Viewer 已是雏形）

### 2.2 切入点

- **AI 原生**：三竞品都没做好 AI
- **内容智能动作**：JSON 格式化预览、HTML 浏览器预览、图片模板化保存——Maccy/Paste/Raycast 均无
- **中文场景**：Maccy/Paste 国内推广弱
- **轻量隐私**：Rust + Tauri，本地优先，无云端

### 2.3 风险

- ⚠️ Apple 可能在 macOS 系统更新中推出原生 AI 剪贴板，本项目价值大降
- ⚠️ Raycast 已强化 AI 剪贴板
- ⚠️ 商业化天花板低（Paste 团队多年仍小作坊）

## 四、三个核心智能动作详细规格

### 4.1 F1 JSON 智能动作（**最高优先级**）

#### 三段式交互

```
┌─ 阶段 1：悬浮窗右侧预览面板（hover/聚焦即显示）
│   - 悬停或键盘聚焦任一条目，右侧 PreviewPane 展示整条内容
│   - 文本/HTML 显示原文；JSON 格式化高亮；图片预览；文件列出路径
│
├─ 阶段 2：完整查看（快捷键 / 点击）
│   - 默认快捷键：⌘J
│   - 或点击悬浮窗条目右侧的"在新窗口打开"按钮
│   - 弹出独立 JSON 查看器窗口（**支持多开**）
│   - 支持搜索、折叠、复制路径
│
└─ 阶段 3：外部工具（可选）
    - 设置中配置"外部 JSON 工具"（如 VS Code：探测 `code` in PATH，回退 `/Applications/Visual Studio Code.app`）
    - 悬浮窗条目右键菜单"在 VS Code 中打开"
```

#### 独立查看器窗口 UI

```
┌─ JSON 查看器 ─────────────────── [□ ✕]─┐
│ 📄 [#id]  [2空格] [4空格] [压缩] [复制] [外部] [✕]   │
│ 🔍 [搜索…]                                     │
│ ┌──────────────────────────────────────┐   │
│ │ 1  {                                  │   │
│ │ 2    "name": "demo",                 │   │
│ │ 3    "items": [                       │   │
│ │ 4      { "id": 1, "value": "a" },    │   │
│ │ 5      ...                            │   │
│ │ 6    ]                                │   │
│ │ 7  }                                  │   │
│ └──────────────────────────────────────┘   │
└─────────────────────────────────────────────┘
```

#### 配置项

- 外部 JSON 工具路径（默认探测 VS Code）
- 缩进（2/4/Tab）
- 独立窗口快捷键（默认 `⌘J`）
- 主题（亮/暗/跟随系统）

### 4.2 F2 HTML 智能动作（**次优先级**）

#### 双触发方式

| 触发                 | 行为                                                        |
| ------------------ | --------------------------------------------------------- |
| **方式 1：在悬浮窗中**（默认） | 复制 HTML → 悬浮窗条目显示"🌐 在浏览器打开"按钮 → 点击触发                     |
| **方式 2：全局快捷键**     | 默认 `⌘⇧H` → 直接将当前剪贴板 HTML 写入临时文件并 `open` 默认浏览器，**无需调出悬浮窗** |

#### 临时文件管理

- 路径：`~/Library/Caches/<App>/html-preview/`
- 命名：`{yyyyMMdd_HHmmss}_{uuid 前 8 位}.html`
- 清理策略：保留 7 天（可配置），超过自动删除（后台定时任务，每小时一次）

#### 配置项

- 浏览器选择：MVP **仅支持系统默认浏览器**（`open` 命令，v0.2 再加指定浏览器 `open -a "Google Chrome"`）
  - 理由：99% 用户用系统默认浏览器，先聚焦核心功能验证需求
- 是否保留文件
- 快捷键开关
- 全局快捷键（默认 `⌘⇧H`，可改）

#### 通知策略

- **完全不弹通知**（用户已在悬浮窗操作，知道发生了什么）
- 静默模式下图片保存也是同样策略

### 4.3 F3 图片智能动作（**第三优先级**）

#### 两种模式

| 模式          | 行为                                                       |
| ----------- | -------------------------------------------------------- |
| **手动（默认）**  | 复制图片 → 悬浮窗条目显示"💾 保存"按钮 → 点击弹原生保存对话框（NSSavePanel，记忆上次路径） |
| **自动（无通知）** | 复制图片 → 后台线程按命名模板静默保存到指定目录 → 悬浮窗状态栏显示总数，**不弹任何通知**        |

#### 命名模板变量

- `{date}` → `20260728`
- `{time}` → `143052`
- `{datetime}` → `20260728_143052`
- `{app}` → 来源应用名（Mac 经 `NSWorkspace.frontmostApplication.localizedName` 获取，**Mac 上真正可用**）
- `{type}` → 图片格式（png/jpg）
- `{n}` → 自增序号（防重名）
- `{hash}` → 内容 hash 前 6 位

#### 模板示例

- `{date}_{app}_{n}.png` → `20260728_Safari_001.png`
- `Screenshots/{datetime}_{hash}.png` → `Screenshots/20260728_143052_a1b2c3.png`

#### 配置项

- 默认保存路径（空 = `~/Desktop/ClipForge`）
- 命名模板
- 手动/自动模式（**默认手动**）
- 图片格式保留 / 转 JPEG

#### 决策记录

- **延迟方案演进**：
  - 原始方案：自动模式下 0.5-1s 延迟合并通知窗口
  - 最终方案：磁盘写入**立即执行**（后台线程，用户无感），通知策略改为**完全不弹通知**
  - 结论：因"不通知"方案彻底消除打扰问题，无需延迟机制
- **通知策略**：自动保存模式**无通知**，仅在悬浮窗状态栏显示总数
- **后台线程**：图片保存走独立线程，不阻塞主进程

## 五、用户体验

### 5.1 快捷键

| 快捷键            | 功能                                  |
| -------------- | ----------------------------------- |
| `⌘⇧C`          | 显示/隐藏主悬浮窗（默认，可改；避开 `⌘⇧V` 粘贴并匹配样式冲突） |
| `⌘J`           | 在独立窗口打开当前选中的 JSON（可绑定多条）            |
| `⌘⇧H`          | 直接用浏览器打开剪贴板中的 HTML                  |
| `Esc`          | 隐藏悬浮窗；在 JSON 独立窗口中关闭该窗口             |
| `↑/↓`          | 在列表中上下移动                            |
| `Enter`        | 粘贴选中项，并自动关闭主窗口（还原上下文）               |
| 可打印字符          | 自动聚焦搜索框并输入内容触发搜索（输入框聚焦时不拦截）         |
| `⌘P`           | 切换置顶                                |
| `Delete` / `⌫` | 删除选中项                               |
| 点击窗口外          | 失焦自动隐藏主面板（唤起后 150ms 内的失焦忽略，避免抖动）    |

> 唤起位置：`⌘⇧C` 在**光标处**弹出主面板（Spotlight/Maccy 风格）；靠近菜单栏/Dock 时自动翻转/贴边，保证不超出当前显示器并避开菜单栏（顶部 ~25px inset）与 Dock。

### 5.2 通知策略

- **静默模式**（图片自动保存、HTML 浏览器打开）：**完全不弹通知**
- 手动操作时通过悬浮窗状态反馈
- 错误情况：菜单栏图标变化 + 悬浮窗内提示

### 5.3 主题与外观

- 跟随系统（默认，NSAppearance）/ 亮色 / 暗色 可手动切换
- 外观由原生 vibrancy 毛玻璃默认外观承担（背景色固定 alpha 0.85）
- 实现要点：JS 在 `<html data-theme>` 上切换（不依赖 `@media`）；每个 Tauri 窗口是独立 webview，设置变更经后端 `settings://updated` 事件跨窗口同步；毛玻璃由 Tauri `windowEffects`（NSVisualEffectView vibrancy）原生承担
- 背景：原生 vibrancy（sidebar/popover，`backdrop-filter` 仅作 webview 内兜底）
- 圆角：10px 容器 / 4px 元素（原生 NSWindow contentView.layer.cornerRadius）
- 主色：`#007AFF`（macOS Blue）
- 多语言：支持中/英文切换，设置变更热加载（无需重启）

### 5.4 菜单栏与 Dock

- 菜单栏配件（menu extra）：左键切换主面板，菜单含 显示主面板 / 设置 / 退出
- **隐藏 Dock 图标**（LSUIElement，默认开）：应用仅以菜单栏配件形态存在，不占 Dock 位（Maccy 式），可设置关闭

- **v3**（~8 月）：跨平台同步（WebDAV/网盘绕过云）、App Store 上架评估
- **v4**（~10 月）：iOS 联动（Universal Clipboard 增强）；窗口交互修复（Esc 关闭 JSON 窗口、Enter/双击复制后关闭主窗口、输入字符自动聚焦搜索框）；窗口定位修复（全屏应用浮现、副屏光标定位）；JSON 窗口标题改为打开序号；热键触发稳定性修复；Alt+Tab 切换器不再乱跳
